FAQ

What are AI Agent Skills?

AI Agent Skills are reusable text-based instructions (SKILL.md files) that you install into your AI coding agent (Claude Code, Cursor, OpenClaw, Codex). Once installed, the agent loads the skill automatically when your question matches its trigger. Each Gingiris skill is a battle-tested growth playbook — installing one is like adding a specialist consultant to your agent.

How do I install these skills?

Install via skills.sh CLI: npx skills add Gingiris-1031/<slug> — works with Claude Code, Cursor, OpenClaw, Codex, and other compatible agents. All skills are also available on Hugging Face. The downloadable community skills are open-source under the MIT License.

Are these skills free?

Yes. The downloadable community skills are MIT licensed and remain free. Hosted Gingiris Pro execution, private datasets, and managed services are separate commercial products.

What is the meta-router (gingiris-skills)?

gingiris-skills installs the full 60-skill collection. Its /gr router classifies direct tasks or broad growth problems, loads the narrowest specialist, executes it in the same task, and only hands off when the result creates a concrete next job.

When should I use Gingiris tools or advisory services?

Use the free skills first. Browse the Gingiris tools directory when you need live data, monitoring, enrichment, or execution software. Use Gingiris advisory services for high-stakes decisions, ongoing 0-to-1 support, or a customized AI growth employee.
