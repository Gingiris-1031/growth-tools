Key takeaways

  • Separate owned, user and external source lines. / 区分自有、用户、外部素材。
  • Connect each channel to an audience task and next action. / 渠道对应具体人群与下一步。
  • Review evidence, voice and disclosure before adaptation. / 出处、口吻、脱敏三道闸。
  • Track acceptance, readback and metrics separately. / 提交、回读、数据分别记录。

What this is

Coordinate a repeatable content operation within your real capacity.
从真实素材出发，选择渠道、安排产能、审稿分发，并区分内容表现与业务结果。

Version 1.0.0 · Includes templates; no private source material. Publishing and messaging require authorization. / 含操作模板，不含私人素材；发布和发消息需授权。

Use this skill

An AI agent instruction package: it guides a supported agent through a task. Results depend on your inputs, connected tools and review.

What to provide

Audience and objective, authorized source material, channels, team capacity and any available history.

What you get

A channel/capacity card, source register, weekly calendar, parent/variant map, delivery ledger and review memo as needed.

Starter prompt

Use gr-ai-content-ops to plan one week with 6 hours, an approved demo and no analytics. Flag missing evidence and prepare drafts only.

Example decision

Illustrative example: A private customer transcript without publication permission stays out of public drafts; the approved demo anchors the pilot instead.

Read the maintained SKILL.md and templates on GitHub

How to use / 使用流程

  1. 1

    Scope / 确定范围

    Provide audience, sources, channels, capacity and the requested endpoint.

  2. 2

    Plan and review / 排期与审稿

    Choose a feasible week and review evidence, voice and permissions.

  3. 3

    Deliver and learn / 交付与复盘

    Prepare drafts; execute only authorized distribution and record verified receipts and measurement gaps.

Limits / 使用边界

  • No invented customer stories, quotes or analytics. / 不编造客户故事、引用和数据。
  • Cadence and platform tactics are hypotheses, not growth guarantees. / 频次与平台打法需要测试。
  • An uncertain submission is reconciled before retrying. / 提交状态未知时先核对，避免重复。

FAQ

How do I install this skill? / 如何安装？

npx skills add Gingiris-1031/gingiris-skills --skill gr-ai-content-ops

Can I use it without analytics or API keys? / 没有数据和 API key 可以用吗？

Yes, for planning from supplied material. It marks missing evidence and creates a pilot; live analytics need platform access.

Does it automatically publish or message contributors? / 会自动发布或联系嘉宾吗？

No. It defaults to a draft pack and requires explicit authorization for publishing or messages.
