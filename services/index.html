「AI 增长员工」到底交付什么

你买到的不是咨询时间，是我的方法论的可执行副本——装进你自己的 Claude Code，用你的业务数据校准过。交付物四件套：

  1. 1

    Skills 全家桶安装（按产品类型选装）

    开发者工具 / 开源 / B2B SaaS 默认装配：go-global（出海全周期）+ launch（发布/PH）+ seo-geo & seo-geo-agent（SEO/GEO 双引擎）+ kol-outreach（红人价格库+砍价 SOP）+ user-interview（Token Top10 访谈法）+ b2b-growth（含 2B 打单交付框架）。2C 产品切换 2C 适配层 + aso-growth + ugc-matrix；执行件按需加装（排名巡逻 / 博客产出 / 竞品追踪 / 一鱼多吃分发 / 推特代笔）。

  2. 2

    业务校准（这一步才是钱花的地方）

    AI 从「会方法论」变成「懂你业务」：ICP 与 3-5 家竞品库喂进常驻上下文；KPI 口径校准到具体数字（激活的行为定义、CAC 红线注册 $5-8 / 付费 <$50、注册→付费合格线 >5%）；按 ARR 阶段地图定死渠道建议边界；品牌 voice 与脱敏红线；GA4 / Search Console / 后台指标接入工作流——AI 的建议基于你的真数据而不是想象。

  3. 3

    AI 员工管理范式

    AI 每天写日报（做了什么、数据变化、明天计划）；SEO 员工 / 内容员工 / 竞品监控员工分岗位分对话框，各背各的 KPI；你只需要每周一次周会验收——像管人一样管 AI。

  4. 4

    交付物清单

    ✅ 装配+校准完成的 Claude Code 工作环境 ✅ 《AI 员工操作手册》（团队任何人可上手）✅ 七阶段交付地图定位（商业模式→MVP→Campaign→PMF→长线 SOP→二次发布→2B 打单——标出你现在在哪、AI 先攻哪一段）。

FAQ

三档服务怎么选？

单点决策（定价、渠道、发不发 PH）选单次咨询；0-1 阶段需要每周判断力和督导选陪跑；已有执行团队或 AI 基建、缺的是方法论，选 AI 增长员工搭建包。三档可叠加：多数客户的最优解是搭建包 + 前两个月陪跑，第三个月起只留年费。

AI 增长员工搭建包需要什么前提？

两个前提：贵司有 Claude Code（或同级 agent）环境与 API 预算；有基础数据后台（GA4 / 后台指标任一即可）。满足这两条，2-3 个工作日即可完成装配与校准，外加 2 小时交付培训。

¥12,000 的年费包含什么？

skills 全年更新、每月 1 次 45 分钟校准 call、平台重大变化的 playbook 补丁（PH 规则 / GEO 算法 / 渠道行情变化）、新 skill 优先使用权。不包含代运营执行、内容代写、投放代管——需要人来干的活属于陪跑服务（¥7,000/月）。

这和代运营有什么区别？

代运营卖的是人力，这里交付的是判断力：单次咨询和陪跑给你人的判断力，AI 增长员工搭建包给你判断力的可执行副本——装在你自己的 Claude Code 里、用你的 ICP、竞品库、KPI 口径和真实数据校准过，7×24 干活，且资产归你。
