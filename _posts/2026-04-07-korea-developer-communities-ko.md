2023년 초, 상하이 오피스에서 한국 시장을 처음 본격적으로 들여다봤다. AFFiNE의 GitHub 스타 데이터를 분석하다가 한국 IP에서 오는 트래픽이 예상보다 훨씬 많다는 걸 발견했기 때문이다.

그런데 어디서 오는지 알 수가 없었다 — 한국 개발자 커뮤니티에 대해 아는 게 없었다.

6개월 간 한국 개발자 커뮤니티를 조사하고 직접 참여해본 결과를 여기 공유한다.

## 한국 개발자 생태계 이해하기

한국 개발자 커뮤니티는 독특한 특성이 있다.

**높은 기술 수준**: 카카오, 네이버, 라인 같은 대형 IT 기업들이 운영하는 기술 블로그는 세계 수준의 엔지니어링 콘텐츠를 생산한다.

**커뮤니티 충성도**: 한번 신뢰를 얻으면 강력한 입소문이 퍼진다. 반대로 스팸이나 홍보성 글은 즉각 차단된다.

**언어 장벽**: 영어 콘텐츠는 읽히지만, 한국어로 직접 소통하면 신뢰도가 확연히 다르다.

이 세 가지를 이해하고 접근해야 한다.

## OKKY: 한국 최대 개발자 포럼 공략법

OKKY(okky.kr)는 한국에서 가장 오래되고 규모가 큰 개발자 커뮤니티다.

월 활성 사용자 수십만 명, 다양한 게시판 구성: 질문/답변, 자유 토론, 취업, 스터디 모집.

**해외 스타트업을 위한 OKKY 접근 전략:**

1. 먼저 100개의 질문에 답하라 — 진심으로, 한국어로
2. 자신의 오픈소스 프로젝트와 관련된 기술 블로그 글을 공유하라 (광고 아닌 지식 공유)
3. "저희 제품을 써보세요" 식의 직접 홍보는 금물
4. 커뮤니티에서 신뢰가 쌓인 후 자연스럽게 소개

## 대기업 기술 블로그의 활용 방법

카카오, 네이버, 라인, 배달의민족의 기술 블로그는 단순히 읽는 콘텐츠가 아니다.

이 블로그들을 팔로우하면:
- 한국 개발자들이 어떤 기술에 관심 있는지 알 수 있다
- 어떤 문제를 풀고 있는지 파악할 수 있다
- 내 제품이 어떤 맥락에서 소개될 수 있는지 찾을 수 있다

실제 전략: 카카오 기술 블로그에서 AFFiNE과 관련된 주제 (블록 에디터, 협업 도구, CRDT)를 다룬 포스팅을 찾고, 해당 저자에게 직접 연락했다. 기술적 토론을 먼저 시작했고, 나중에 자연스럽게 AFFiNE을 소개했다.

## GDG, AWSKRUG: 커뮤니티 밋업 공략법

GDG Korea와 AWSKRUG은 정기적인 오프라인/온라인 밋업을 운영한다.

발표자로 참여하는 것이 가장 효과적이다.

발표 제안 팁:
- 당신의 오픈소스 경험에서 나온 기술적 인사이트를 주제로 삼아라
- 제품 홍보가 아닌 지식 공유 포맷으로
- 한국어 발표가 가능하면 훨씬 좋다 (번역 지원 요청도 가능)

AFFiNE 팀원이 GDG Seoul에서 CRDT 구현에 관해 발표한 후, 그 한 번의 발표에서 60명의 한국 기여자 후보가 생겼다.

## 인프런: 한국 개발자 교육 플랫폼의 힘

인프런은 단순 강의 플랫폼이 아니다. 활발한 커뮤니티와 Q&A가 있는 개발자 생태계다.

인프런에서 당신의 오픈소스 도구와 관련된 무료 튜토리얼 강의를 만들어보라.

(무료 강의는 마케팅이 아니라 진짜 교육이어야 한다 — 한국 개발자들은 바로 구별한다.)

## 한국 개발자 커뮤니티 진입 체크리스트

해외 스타트업이 한국 개발자 커뮤니티에 진입할 때 반드시 해야 할 것들:

**준비 단계 (2-4주 전)**
- 한국어 README 또는 한국어 랜딩 페이지 준비
- 주요 커뮤니티 5개 가입 및 2주간 관찰
- 한국어 가능한 팀원 또는 커뮤니티 매니저 확보

**진입 단계**
- OKKY에서 관련 질문 20개 이상 답변 후 소개
- KossLab에 오픈소스 프로젝트 등록
- DEVOCEAN에 기술 블로그 포스팅

**유지 단계**
- 월 1회 이상 커뮤니티 기여 (답변, 포스팅)
- 분기별 한국 밋업 참여 또는 발표

## 마무리: 신뢰가 먼저다

한국 개발자 커뮤니티에서 가장 중요한 것은 하나다 — 신뢰.

기술적으로 탁월하고, 한국어로 소통하고, 스팸 없이 진심으로 참여하면 한국 개발자 커뮤니티는 강력한 입소문 채널이 된다.

AFFiNE의 한국어 README 추가와 커뮤니티 참여 이후 한국발 GitHub 스타와 기여자 수는 3개월 만에 2배가 됐다.

한국 시장은 크지 않을 수 있다. 하지만 한국 개발자들은 품질을 알아보고, 좋은 것을 빠르게 퍼뜨린다.
