AFFiNE：一切方法论的原点 — 24 个月 0 到 60K star

一周 6000 star、24 个月 60K+、280+ 国家用户——作为联合创始人 & COO 从 0 做起的全部海外增长。

开源增长 2022–2024 24 个月 60K+ star

By Iris Wei (生姜) · ex-COO of AFFiNE (60K+ GitHub stars) · 30× Product Hunt #1 · 105+ 项目实战

关键要点

  • 定位先于一切：市面上第一个「文档 + 白板」结合的工具——一句话讲得清，才传播得动。
  • README 与官网互为引流闭环，GitHub 本身就是最大的流量入口之一。
  • 近百场用户访谈驱动迭代方向，增长和产品从来不是两条线。
  • Product Hunt 战役与顶级 Hunter（Chris Messina）合作，把发布做成事件而不是上架。

背景与挑战

2022 年 8 月 3 日凌晨 1:47，我们把 AFFiNE 推上了开源社区。协作工具赛道巨头环伺， 一个新项目要在发布当天就被全球开发者记住，靠的不是功能列表，而是一句话能讲清的差异化。 作为联合创始人 & COO，我负责了从 0 到 1 的全部海外增长。

关键数据

发布第 1 周 star 数6,000
24 个月累计 star60,000+
用户覆盖国家和地区280+
融资金额$10M

打法拆解

  1. 1

    差异化定位

    把产品钉死在「市面上第一个文档 + 白板结合的工具」这一个记忆点上，所有渠道口径统一，不贪多。

  2. 2

    README 与官网的引流闭环

    GitHub README 按着陆页标准运营，与官网互相导流，让每一个 star 背后都有一条可追踪的注册路径。

  3. 3

    近百场用户访谈驱动迭代

    增长信号直接回灌产品：访谈里反复出现的需求进 roadmap，反复出现的语言进文案。

  4. 4

    Product Hunt 战役

    与顶级 Hunter Chris Messina 合作，把 PH 发布当成一场有预热、有节奏、有承接的战役来打。

结果与沉淀

一周 6000 star，一个月破 10K，24 个月做到 6 万+ star，用户覆盖 280 多个国家和地区、 总量超百万，融资 $10M。这一役沉淀下来的定位、README、访谈与发布方法论， 成为后来 105+ 项目咨询的原点。
